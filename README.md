## How to Use This Repository

1. **Finding a Pattern**
   - Check the `/patterns` directory
   - Each pattern includes:
     * Recognition signals
     * Common approaches
     * Template solutions
     * Related problems

2. **Solving Problems**
   - Solutions are in `/solutions`
   - Each solution includes:
     * Pattern recognition
     * Approach explanation
     * Code implementation
     * Edge cases
     * Time/Space complexity

3. **Adding New Solutions**
   - Use templates from `/templates`
   - Follow the standard format
   - Link to related patterns
   - Add key insights learned

## How to Add New Content

### Adding a New Pattern
1. Choose the appropriate category folder in `/patterns/`
2. Create a new markdown file using the pattern template:
   ```bash
   cp templates/pattern-template.md patterns/category/new-pattern.md

### Adding a New Solution

1. Create a new folder in /solutions/:
    ```bash
    mkdir solutions/XXXX-problem-name
    cp templates/solution-template.md solutions/XXXX-problem-name/README.md

2. Fill out the solution template
3. Link to relevant patterns

### Adding a New Category

1. Create new category directory:
    ```bash
    mkdir -p patterns/new-category
    cp templates/category-readme-template.md patterns/new-category/README.md
